01 直接回答

R7F701690 是 64-pin LQFP，不是 100-pin。不能把 100-pin 方案 1:1 照搬。

结论 8 路硬件 PWM + 1 路软件 PWM。 P10_14 在 64-pin 上没有 TAUB0O7，只能用 PWGA19O；P0_6 在 64-pin 上没有硬件 PWM，用 OSTM0 软件定时器 生成。

64-pin 第 59 脚，第 1 复用 PWGA19O。PWGA19 属于 PWM-Diag，40 MHz 时钟域，12 位周期；200–400 kHz 下占空比步进 0.5%–1%。

P0_6

64-pin 第 11 脚，复用只有 INTP2 / DPIN10 / SELDP2。不能配成 TAUD/TAUB/TAUJ/PWGA，改用 OSTM0 自由运行比较 + INTOSTM0 中断翻转 GPIO。

04 P0_6：OSTM0 软件 PWM

P0_6 没有硬件 PWM，用 OSTM0 自由运行比较模式 + INTOSTM0 中断翻转 GPIO。最终是 8 路硬件 PWM + 1 路软件 PWM。

方案

OSTM0 自由运行比较

32 位计数器从 0 向上计数；每次比较匹配进入 pwm_sw_isr()，翻转 P0_6，并把下一次比较值设为 CMP + 高/低计数。

时钟

CPUCLK_L = 60 MHz

200–400 kHz 时 N = 150–300。400 kHz 占空比步进约 0.67%，200 kHz 约 0.33%。

代价

CPU 负载 + 抖动

400 kHz 时约 80 万次中断/秒。120 MHz CPU 下每 150 周期一次中断，估计 20%–50% CPU；抖动取决于中断延迟和优先级。

实现要点 P0_6 配成 GPIO 输出；OSTM0 用自由运行比较模式（CTL=0x02），在 INTOSTM0 中断里调用 pwm_sw_isr()。ISR 必须短，建议给 INTOSTM0 较高优先级，避免其他长中断造成抖动。
如果允许改板 仍可把 P0_6 网络改到 P10_4（TAUD0O9，80 MHz，pin 2），把 PWM9_USE_P10_4_FOR_P0_6 设为 1，换回硬件 PWM。P10_5（TAUD0O11）和 P10_7（TAUD0O15）也可作为备选。
不要做的事 不要按 PWGA35 配置 P0_6（64-pin 没有 PWGA35）；也不要在 P0_6 上找 TAUD/TAUB/TAUJ 复用，它只有 INTP2/DPIN10/SELDP2。

07 CS+ 集成

  1. 选择正确器件
    CS+ 工程选 R7F701690（RH850/F1KM-S1，64-pin LQFP），确认 CCRH850 编译器。
  2. 加入 64-pin 文件
    加入 pwm9_64.c、pwm9_64.h；把 main_pwm_example_64.c 的内容合并到你的 main.c。
  3. 使能模块时钟
    TAUD0、TAUJ0–3、PWBA0、PWGA19、PWSA0、OSTM0。PWGA19 是 PWM-Diag 通道 19，不是 PWGA35；64-pin 只有 PWGA0–23。
  4. 核对 PCLK 宏
    PWM_PCLK_IPERI1_HZ、PWM_PCLK_IPERI2_HZ、PWM_PCLK_ATAUJ_HZ、PWM_SW_PCLK_HZ 改成实际时钟树频率（默认 80/40/40/60 MHz）。
  5. P0_6 软件 PWM / INTOSTM0
    默认用 OSTM0 软件 PWM。在 CS+ / Smart Configurator 使能 OSTM0 和 INTOSTM0 中断，把 INTOSTM0 向量指向 pwm_sw_isr()，并给较高优先级。若直接把 pwm_sw_isr 注册为向量函数，按工程 INTC2 写法清 INTOSTM0 标志；用 Smart Configurator 的 wrapper 调用它则不需要额外处理。若改板到 P10_4，把 PWM9_USE_P10_4_FOR_P0_6 设为 1。
  6. 端口保护
    如果启用了 Port Protection，先按 Section 5 解锁 PPCMD，否则 PFC/PMC 写不进去。
  7. 测量
    先测 P10_6、P10_14、P10_2，再测 P0_6 软件 PWM。P0_6 没有波形时优先检查 OSTM0 模块时钟和 INTOSTM0 向量。
现象原因处理
P0_6 没有波形OSTM0 没使能，或 INTOSTM0 没指向 pwm_sw_isr()使能 OSTM0 模块时钟；注册 INTOSTM0 向量；检查 pwm_sw_isr 是否被调用
P0_6 抖动大ISR 延迟 / 其他中断阻塞提高 INTOSTM0 优先级；缩短 ISR；避免长时间关中断
P10_14 没有波形还按 TAUB0O7 配置改为 PWGA19O：PFC alt=0；PWGA19_TCR.TOE=1；SLPWGA0 bit19=1
P10_14 频率不对PWGAPRDSL0/SLPWGA0 用错 bitPWGA19 用 SLPWGA0 bit19、PWGAPRDSL0 bit19；PWGAPRD 共享
P10_6 没有波形TAUD0 CH13 没使能，或 PFC 没设CH12 主 / CH13 从；P10_6 PFC=0/0/0、PM=0、PMC=1
频率偏大/偏小PCLK 宏或 PRS 不对核对 64-pin 实际时钟；200–400 kHz 下 PRS=0

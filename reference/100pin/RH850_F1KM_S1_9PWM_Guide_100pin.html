01 结论与风险

按 RH850/F1KM-S1 100-pin 复用表逐脚核对后的结论。

P0_6 · 重点

没有 TAU / TAUB / TAUD

100-pin 第 13 脚。唯一硬件 PWM 复用是 PWGA35O（第 5 复用）。必须走 PWM-Diag 模块，不能按 TAUD/TAUB/TAUJ 配置。

P10_14 · 重点

TAUB0O7 · 第 4 复用

100-pin 第 88 脚。TAUB0 的 CH7 只能做从通道，主通道用 CH4。时钟域 CKSCLK_IPERI2，最大 40 MHz。

P10_6 · 重点

TAUD0O13 · 第 1 复用

100-pin 第 80 脚。TAUD0 group 12–15：CH12 主 / CH13 从。时钟域 CKSCLK_IPERI1，最大 80 MHz。

关键限制 P0_6、P10_14、P8_5、P0_2（若选 TAUJ2） 的定时器时钟上限是 40 MHz。在 400 kHz 时只有 100 个计数周期，占空比最小步进约 1%，频率步进约 4 kHz。如果这两项指标不够，必须改引脚，或把 P0_2 改为 TAUD0O6（80 MHz，但会与 P10_2/P10_3 共用 CH4 周期）。
推荐方案 使用 方案 B：九路独立频率。8 路定时器 PWM + 1 路 PWGA35；所有通道都能独立设置频率和占空比。代码和本文的参数计算器都按方案 B 编写。

周期值：TAUD/TAUB/TAUJ 为 CDR_master；PWGA 为 PWGAPRD。占空值：TAUD/TAUB/TAUJ 为 CDR_slave；PWGA 为 CRDR（100% 时显示 0x1000，输出强制高）。

06 公式与寄存器

TAUD / TAUB / TAUJ

主通道：interval timer mode，只定周期，不输出。

从通道：one-count mode，定高电平时间，输出到引脚。

计数时钟 = PCLK / 2^PRS      (CK0, PRS = 0..15)
周期     = (CDR_master + 1) × 计数时钟周期
频率     = 计数时钟 / (CDR_master + 1)
占空比   = CDR_slave / (CDR_master + 1) × 100%

0%   : CDR_slave = 0
100% : CDR_slave ≥ CDR_master + 1

TAUD0 / TAUB0 是 16 位；TAUJ 是 32 位。同一 group 的所有通道必须使用相同 CKS；不同 group 可以用不同 CKS。

PWGA35

PWMCLK = PCLK                    (BRS = 0)
PWMCLK = PCLK / (2 × BRS)        (BRS = 1..2047)

PWM周期 = (PWGAPRD + 1) × PWMCLK周期
占空比  = (CRDR - CSDR) / (PWGAPRD + 1) × 100%

CSDR = 0，CRDR = 高电平计数
CRDR 的 bit12 = 1 → 输出强制高（100%）

PWGAPRD 是 12 位。PWGAPRD 在计数期间禁止修改；改频率要先停 PWGA35，再改周期并重启。

08 CS+ 集成步骤

  1. 新建 / 打开 CS+ 工程
    选择 RH850/F1KM-S1 对应型号（R7F7016xx，按你的具体料号选择）。确认工程使用 CCRH850 编译器。
  2. 加入文件
    把 pwm9.c、pwm9.h 加入工程；main_pwm_example.c 只作参考，把内容合并到你的 main.c。
  3. 使能模块时钟
    在 Smart Configurator 或 MSTPCR 中使能 TAUD0、TAUB0、TAUJ0–3、PWBA0、PWGA35、PWSA0。时钟没开时，寄存器写入会被忽略，引脚也不会有波形。
  4. 核对 PCLK 宏
    打开 pwm9.h，把 PWM_PCLK_IPERI1_HZ、PWM_PCLK_IPERI2_HZ、PWM_PCLK_ATAUJ_HZ 改成你工程时钟树里的实际频率。默认值是手册最大值：80 / 40 / 40 MHz。
  5. 调用初始化
    在时钟、模块时钟、端口初始化完成之后调用 pwm9_init()。不要在 R_SystemInit() 之前调用。
  6. 设置目标参数
    例如 pwm9_set_freq_duty(PWM_P10_6, 350000UL, 250U) 表示 P10_6 输出 350 kHz、25%。
  7. 编译 / 烧录
    Clean Build → Build → 烧录。若端口保护开启，先按手册 Section 5 解锁 PPCMD；否则端口复用寄存器可能写不进去。
  8. 测量确认
    用示波器/逻辑分析仪测 P10_6、P10_14、P0_6。先看频率，再看占空比，最后看上升沿抖动。
CS+ 注意 如果工程里已经用 Smart Configurator 生成了 TAUJ/TAUD/TAUB 的初始化代码，不要再让两套代码同时配置同一通道。保留一套：要么用本文代码，要么用 Smart Configurator 生成的 API，避免最后写入的配置覆盖前面的设置。
